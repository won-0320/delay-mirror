# 딜레이 미러

배드민턴 수업에서 학생이 자기 스윙 폼을 바로 확인하는 카메라 앱입니다.

- 주소: https://delay-mirror.vercel.app
- **지연 화면**: 카메라 영상을 3~20초 늦게 보여줍니다. 멈추면 되감기와 슬로모션(0.25배·0.5배)으로 다시 볼 수 있습니다.
- **녹화**: 버튼으로 녹화를 시작하고 멈춥니다(최대 60초). 멈추면 바로 다시보기가 나옵니다.
- 영상은 기기 메모리에만 잠깐 머물고 저장·전송되지 않습니다.

## 개발

```bash
npm install
npm run dev     # 로컬 실행
npm run build   # 빌드 확인
```

`main` 브랜치에 푸시하면 Vercel에 자동 배포됩니다.
카메라는 https 또는 localhost에서만 켜집니다.
